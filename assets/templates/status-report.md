# 立正收尾报告

每次"立正"结束输出本报告，让用户一眼看清做了什么。

```
## 立正报告

### 状态
- 仓库：<路径>
- 默认分支：<name>（探测来源：<gh/symbolic-ref/fallback>）
- 远程宿主：<GitHub/GitLab/.../纯本地>
- 判定：<干净态 / 脏态>

### 干净态动作（若适用）
- 拉取：<ff-only 成功 / 分叉停止（原因）>
- 剪枝本地已合并分支：<列表 或 无>
- 剪枝远程已合并分支：<列表 或 无 或 远程不可逆已确认/未确认>
- 下一步建议：<3-5 条可执行方向>

### 脏态动作（若适用）
- 诊断：<WIP 功能 / 构建破损 / 半成品 / ...>
- 修复：<改了什么，为何>
- 测试/lint/build：<结果>
- 文档同步：<已同步 / 无需更新 / 待补充项>
- 版本一致性：<未涉及 / 已 bump 至 vX.Y.Z / tag 计划>
- 提交：<commit hash / message 摘要>

### PR
- <PR 链接 或 "PR 就绪产物已输出，见上方" 或 "gh 不可用，请 gh auth login">

### 下一步建议
- <基于真实信号的 3-5 条可执行方向>
```

## 红线
- 每一项都基于真实采集数据；不编造。
- 动作没做就写"未执行（原因）"，不写成功。
